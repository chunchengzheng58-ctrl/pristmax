QUESTIONS / ANSWERS

Before you begin.

能保证节省多少存储空间？＋

无法为所有数据提供统一比例。重复文件、文本和日志往往更有优化空间；已压缩媒体与加密数据需要单独测试。请使用真实样本测量净节省，包括索引与元数据开销。

什么样的数据去重效果最好？＋

备份快照、虚拟机镜像、日志归档、邮件存储等重复度高的数据效果最佳。已压缩文件（H.264、ZIP、JPEG 等）几乎没有冗余可寻，视频素材的重复帧检测需要单独评估。

视频文件能省多少空间？＋

视频有损降量可显著减小体积，但画质和业务可用性需要逐项目验证。不同于无损归档，视频路径不承诺逐帧还原，请在试点阶段确认是否符合质量预期。

取回的文件和原文件一样吗？＋

无损归档路径应以还原文件的哈希校验确认一致性。视频有损降量是独立策略，不具有同样的保证，请在试点时分别验收。

支持哪些操作系统和存储类型？＋

Linux 服务器为主要支持目标，支持本地磁盘、NFS、SMB、CIFS 等协议。可管理本地目录或挂载点。macOS 和 Windows 端可在 WSL2 环境下运行。

数据加密后还能去重吗？＋

加密后的数据无法做内容级去重，因为相同原始内容加密后结果不同。如需在加密状态下管理，可考虑在加密前做去重，或使用支持相同密钥的透明加密方案。

处理过程会占用多少带宽和内存？＋

去重过程主要为本地计算，不产生外部流量。内存占用与分块大小和并发任务数相关。详细规格请参考 docs.html 中的技术文档。

这个网站会保存我们的文件吗？＋

本网站仅提供产品介绍与文档，不接收企业文件。自部署产品的数据存储、备份、保留与删除策略由实际部署配置决定。

文件处理是在我们自己环境里进行的吗？＋

是的。产品部署与品牌官网完全分离。文件处理在你自己部署的软件中进行，数据不经过任何第三方服务。

如何验证数据完整性和可恢复性？＋

无损路径通过 SHA-256 哈希校验确认还原文件与原始文件一致。每次归档任务生成校验报告，可在控制台查阅。

如何部署第一个试点环境？＋

建议从 100 GB 以内的代表性样本开始，验证节省率和恢复结果。详细步骤请参考 docs.html 中的部署指南，包含环境准备、权限配置和首验流程。

遇到问题可以获得支持吗？＋

当前通过 GitHub Issues 提供社区支持。技术讨论、安全漏洞和功能建议均可在仓库中提交。

可以定制开发或集成吗？＋

源码开放，欢迎基于实际需求做定制集成。如需商业合作，可通过仓库联系。
