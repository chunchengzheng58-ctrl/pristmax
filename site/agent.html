核心功能

智能分析存储，解放你的磁盘空间

📊

存储统计

按文件类型、扩展名、目录分类统计，直观展示存储占用分布。

📦

大文件检测

快速扫描，找出占用空间最多的文件，支持自定义大小阈值。

🔄

重复文件检测

通过 SHA256 哈希检测重复文件，计算可节省的空间。

📁

大目录分析

找出占用空间最大的目录，按大小排序，快速定位问题。

🔌

RESTful API

提供 HTTP API 接口，方便集成到现有系统或开发前端界面。

⚡

高性能扫描

多线程并发扫描，支持大目录快速分析，内存占用低。

快速安装

一条命令，即刻开始使用

方式一：pip 安装

pip install storage-agent
storage-agent --path /your/data --analyze

方式二：从源码安装

git clone https://github.com/chunchengzheng58-ctrl/pristmax.git
cd pristmax
pip install -r requirements.txt
python -m src.pristmax.agent.storage_agent --path /your/data --analyze

方式三：下载安装包

curl -O https://jiangchenghehe.top/downloads/pristmax-api-release.tar
tar -xf pristmax-api-release.tar
cd src/pristmax/agent
python storage_agent.py --help

API 接口

API Examples
# 获取存储统计
$ curl "http://localhost:5001/api/agent/stats?path=/data"

# 查找大文件
$ curl "http://localhost:5001/api/agent/large-files?path=/data&min_size_mb=100"

# 查找重复文件
$ curl "http://localhost:5001/api/agent/duplicates?path=/data"
