Pristmax 部署与试点说明 · 预发布版

目前未发布正式安装包，源码仓库已公开，使用范围以仓库许可证为准。本文用于已有源码的开发与试点评估，不表示产品已通过生产验收。

01 / 官网与产品分开

官网是独立静态网站，只展示介绍、文档与发行状态。产品在企业自己的环境中运行；本地控制台与 API 不应直接暴露到公网。

02 / 安装与开发环境启动

已有本项目源码时，可在隔离的测试环境中运行以下命令。先准备 Python、依赖与 FFmpeg；视频处理需要单独检查 FFmpeg 是否可用。

python -m pip install -r src/pristmax/requirements.txt
python main.py --host 127.0.0.1 --port 5001

启动后访问 http://127.0.0.1:5001。首次按界面完成账号配置。当前部分统计与模块仍使用演示数据，不能作为真实节省率证明。

03 / 试点验收

  1. 准备代表性样本与独立原件，记录字节数、文件哈希、类型与访问频率。
  2. 先验证无损路径的逐字节恢复，再单独评估视频降量的画质与业务准确率。
  3. 计算包含索引、元数据与副本的净存储占用，同时测量处理时间与恢复时间。
  4. 覆盖任务中断、容量不足、损坏检测与权限隔离。通过恢复演练后再扩大范围。

04 / 发行与开源

正式发行将提供版本说明、安装包校验值、支持的平台与升级路径。源码参见 GitHub 仓库；正式安装包尚未发布。

05 / 数据保留边界

无损压缩与去重是数据的编码方式，不等同于“系统从未保存数据”。自部署环境仍需明确工作目录、缓存、日志、备份和删除策略。视频有损降量与原文件无损归档应分开配置和验收。
