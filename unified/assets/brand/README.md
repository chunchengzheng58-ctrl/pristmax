# Pristmax 品牌标识与迁移

2026-09-17：品牌更名，现行标识为三片曲面围合的纯图形，不包含字母构形。图形使用自行编写的 SVG 路径；未完成商标图形近似检索，不保证法律上的唯一性或可注册性。

- `pristmax-symbol.svg`：深墨蓝主标识。
- `pristmax-symbol-light.svg`：深底反白标识。
- `pristmax-symbol-mono.svg`：单色标识。
- 两套控制台及备用仪表盘模板使用同一图形，浏览器图标同步更新。
- 品牌效果图：`docs/design/pristmax-brand-proposal.html`（仓库根目录下）。

新环境变量使用 `PRISTMAX_*`。认证数据库、JWT 密钥、配置路径及配置管理器中的 HOST/PORT/DEBUG 保留旧 `PRISTINE_*` 读取兼容，新值优先。旧配置中的默认品牌显示为新名称。浏览器旧设置进行兼容迁移；已挂载的旧 NAS 路径继续复用。

监控指标前缀现为 `pristmax_`，部署时需同步更新外部监控查询。Compose 服务名及容器名更新，升级时应停止旧实例，再用相同数据卷启动新实例，避免端口冲突；本次未操作运行中的容器。

未修改数据库、客户数据、原始论文及历史对话。旧品牌效果图移至 `docs/design/archive/`，不用于当前展示。名称修改不是商标检索结论。
