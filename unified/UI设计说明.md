# 存序 · 合并工作台界面更新

参考 Semantix 的墨绿与暖白配色、大字排版、细线分隔和留白节奏，独立设计企业控制台。没有复制参考站点的代码、图片或品牌资产。

## 本次范围

- 修改的是 `unified` 合并工作台，保留总览、语义降量、分布式存储、审计四个模块。
- 提取独立 `design.css` 与 `design.js`；主视觉用 CSS 绘制数据层叠图形，无外部字体、图片或前端依赖。
- 使用中文导航、统一指标、表格与状态样式，支持桌面及手机布局、键盘焦点与减少动态效果偏好。
- 补齐导航地址、模块切换后的拓扑重绘、审计筛选与演示 CSV 导出。
- 尚无写入接口的按钮显示演示说明，不模拟创建成功。
- 明确标注演示数据；原有合并页的数值未作为客户真实收益展示。
- 固定 Flask 页面根目录到 unified，并只开放本页 CSS/JS 静态资源，避免不同启动路径误载旧页面。

## 本地运行

在项目根目录执行：

```powershell
python -c "from unified.api import app; app.run(host='127.0.0.1', port=5001, debug=False)"
```

打开 http://127.0.0.1:5001/ 。此处为 UI 与现有合并演示接口预览，不意味着接通无损保管或生产集群。

## 已验证

浏览器检查桌面总览、存储引擎及 390px 手机布局；验证模块切换、说明弹窗和 Escape 关闭、筛选语义审计及 CSV 下载。最终页面无控制台错误。Flask 页面、CSS、JS 与四组读取接口返回正常；Python 源文件不作为静态资源开放。
